## 5. 现场部署注意

- Redis 连接数：每实例 leader3 + status15 + log5 + DWD/在线检查若干；双实例约 50 个，需确认 Redis 上限。
- `status.max_connections` 应 ≥ `max_concurrent_tasks + 2`。
- Pod 终止宽限期（原 30s）小于 day/month 超时 1800s，滚动更新时长任务会被中断，由新主 KILL + 重跑兜底；如需更平滑，延长 terminationGracePeriodSeconds。
- 首次升级：Redis 中无游标时，当前主会把本地账本 seed 到 Redis（`REDIS_STATE_SEEDED` 日志）；之后备机接管才有状态可导入。务必先升级并启动一个实例、看到该日志后再启动第二个。
- ClickHouse 侧 `max_memory_usage` 10GB × 并发 4 = 40GB，确认服务器内存。
